# Week 1 - Project exploration

## Problem

The team was exploring suitable software engineering project topics.

## Relevant Context

Suggested project ideas based on campus needs and participated in the initial discussion.

## Key Observation

A suitable topic needs a defined user group and a workflow that can be demonstrated.

## Solution

Identify the intended users, describe their current difficulty and compare the scope of candidate topics.

## Next Steps

Compare the shortlisted topics and agree on one project.
